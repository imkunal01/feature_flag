# Feature Flag App

A full-stack web application for managing and evaluating feature flags.

## 🏗️ Tech Stack
- **Frontend:** React, Vite
- **Backend:** Node.js, Express, Mongoose (MongoDB)
- **Containerization:** Docker

## 🚀 Getting Started

### Prerequisites
- Node.js (v22 recommended)
- MongoDB
- Docker (optional, but recommended for backend)

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Set the environment variables:
   ```bash
   PORT=3000
   MONGODB_URI=your_mongodb_connection_string
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the server:
   ```bash
   npm start
   ```

## 🧪 Feature Flags

The app supports managing and evaluating feature flags. You can:
- Create, update, and delete feature flags
- Enable or disable features
- Track feature usage and analytics
